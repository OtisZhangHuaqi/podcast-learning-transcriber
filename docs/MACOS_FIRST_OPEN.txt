播客转录助手 · macOS Universal

本软件未使用 Apple Developer ID 签名，也未提交 Apple 公证。请只运行你自己构建或确认 SHA256 无误的文件。

首次打开：
1. 双击 DMG，把“播客转录助手.app”拖入“应用程序”。
2. 双击一次；若 macOS 阻止启动，关闭提示。
3. 打开“系统设置 -> 隐私与安全性”，找到刚刚被阻止的应用，点击“仍要打开”。
4. 输入本机登录密码并确认。此后可正常双击启动。

应用默认把文件写入“文稿/播客转录”，也可以在主界面自行选择目录。
DeepSeek API Key 通过 Electron safeStorage 调用 macOS Keychain 加密保存，不会写入转录结果。

当前包不包含 Apple 公证；Gatekeeper 的首次提示属于预期行为，不代表应用已经损坏。
